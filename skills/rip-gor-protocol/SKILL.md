# RiP GoR Protocol

> Category: analysis — Data analysis, research, and insight generation

## Description

Analysis protocol: Roast (internal critique) + Patricia's input (structured evaluation) = Go with the Result (KEEP, RECYCLE, GARBAGE). Used for prospect evaluation, competitive analysis, and decision triage.

## Instructions

# RiP GoR Protocol

**RiP** = Roast (internal) + Patricia  
**GoR** = Go with the Result

## What It Is

A two-phase analysis protocol that combines brutal honesty with structured evaluation to produce actionable triage decisions.

## Phase 1: Roast (Internal)

Run the target through the Roast skill first:
- **What's wrong with this prospect/idea/competitor?** Find the flaws. Be specific.
- **What's the worst-case outcome?** Call it out.
- **What assumptions are we making?** Challenge every one.
- **Why would this fail?** The roast must hurt — if it doesn't sting, it's not honest enough.

Output from Roast: Unfiltered critique. No sugar-coating. Every weakness exposed.

## Phase 2: Patricia's Input

Patricia (Six Sigma Black Belt, Project Coordinator) processes the roast:

- **Structure the critique** — organize by category, severity, likelihood
- **Identify patterns** — are 20 venues failing for the same reason? Group them.
- **Score each item** — 1-10 on fit, 1-10 on effort, 1-10 on potential return
- **Recommend triage** — KEEP (high fit, high return), RECYCLE (needs more info or different approach), GARBAGE (no fit, no return)
- **Prioritize the KEEP list** — which first, which later, why
- **Identify what's missing** — what would we need to RECYCLE items? What data is missing?

## GoR: Go with the Result

The combined output = GoR verdict:

| Roast Says | Patricia Says | GoR Result |
|------------|---------------|------------|
| "This is solid" | "High fit, high return" | **KEEP** |
| "Lots of problems" | "Missing key data" | **RECYCLE** |
| "This is worthless" | "No fit, no return" | **GARBAGE** |
| "This is solid" | "But effort too high" | **RECYCLE** (not now) |
| "This looks bad" | "Actually just needs different angle" | **RECYCLE** (different approach) |

## When to Use

- Evaluating prospect lists (who to call first)
- Competitive analysis (which competitors to worry about)
- Project triage (which projects to pursue)
- Vendor evaluation (which vendors to partner with)
- Any decision with more than 10 options

## Rules

1. **Roast must come first** — Patricia can't evaluate what hasn't been criticized
2. **Patricia must be consulted** — roast without structure is just complaining
3. **GoR verdicts must have reasons** — never just "KEEP" without saying why
4. **Every GARBAGE item must explain why** — "too small" is vague; "2 bar outlets, seasonal only, $15k/yr liquor spend max" is specific
5. **RECYCLE must include conversion criteria** — what would move it to KEEP?
6. **The result is the decision** — GoR is not advisory, it's the verdict
