# PSDEPOT Flyer Templates

## Quick Start

Generate all flyers:
```bash
cd ~/mortimer/projects/psdepot_prospecting/flyer_templates
python3 generate_flyer.py all
```

Generate specific flyer:
```bash
python3 generate_flyer.py halloween
python3 generate_flyer.py christmas
```

## Template Structure

- `base_template.html` - Master HTML template with all placeholders
- `generate_flyer.py` - Python script to generate event-specific flyers

## Customization

Edit `generate_flyer.py` to modify:
- Event text/messages
- Phone number (888-881-6834)
- Products displayed
- Company info
- Color scheme
